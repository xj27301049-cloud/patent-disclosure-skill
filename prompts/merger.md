# 申请文件增量合并

1. 读取 `iteration_context.md`、基准申请文件和新增材料。
2. 将新增命题标记为 `DF/DV/EV/U/X`，记录来源和是否属于申请日后新增内容。
3. 判断影响范围：权利要求、说明书支撑、效果、附图、检索、专利族边界或样机补强计划。
4. 新增内容改变技术实质时，重跑受影响的检索、攻击、删除测试和 C/D/E 分层。
5. 合并到申请文件：
   - `DF` 可进入结构和步骤；
   - `DV` 只能作为机理性作用；
   - `EV` 可支持原已公开方案的效果；
   - `U/X` 不得写成确定内容；
   - 申请日后形成的新技术内容不得伪装为原申请内容。
6. 执行 `application_self_check.md` 的受影响项目。
7. 另存新版本并更新 `申请文件修订记录.md`。

交付时说明变更章节、事实状态变化、受影响权利要求、是否改变检索/专利族结论和未关闭风险。
