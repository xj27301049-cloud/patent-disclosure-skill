# 申请文件纠正

1. 读取 `iteration_context.md`、基准申请文件和用户纠正。
2. 逐项记录原文、问题、用户确认、证据来源和新的 `DF/DV/EV/U/X` 状态。
3. 分类处理：
   - 结构/动作错误：修改实施方式、附图说明、发明内容及相关权利要求；
   - 权利要求边界错误：重跑删除测试、规避测试和说明书支持检查；
   - 现有技术或区别判断错误：补充检索并更新攻击矩阵；
   - 专利族边界错误：同步检查相邻案件；
   - 编号、术语、引用错误：全文统一；
   - 效果或参数错误：区分设计推导与验证证据，删除不实确定表述。
4. 用户纠正只确认其明确范围，不自动推及其它结构。
5. 执行 `application_self_check.md` 的受影响项目。
6. 另存新版本并更新 `申请文件修订记录.md`。

交付时说明纠正位置、依据、受影响权利要求、是否改变检索/专利族结论和未关闭风险。
