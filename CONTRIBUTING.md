# Contributing Guide

Thank you for your interest in contributing to `patent-disclosure-skill`.

This project is an open-source AI Agent Skill focused on patent-related workflows, including technical disclosure organization, patent analysis, and document generation.

## Ways to Contribute

Contributions are welcome in the following areas:

- Improving patent workflow instructions
- Adding new analysis capabilities
- Improving tools and automation workflows
- Adding examples and documentation
- Reporting issues and suggesting improvements

## Contribution Principles

Please keep contributions:

- Clear and focused
- Well documented
- Easy to review
- Compatible with the existing Skill architecture

## Pull Requests

Before submitting a pull request:

1. Explain the purpose of the change.
2. Describe any workflow or behavior changes.
3. Include relevant documentation updates when needed.

## Security Issues

For security-related issues, please follow the security reporting process described in `SECURITY.md`.

## Community

Constructive feedback and discussions are welcome. Contributions help improve the reliability and usefulness of this AI Skill project.
